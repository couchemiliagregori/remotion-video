# remotion-video

Base reutilizable de Remotion para Reels verticales 1080×1920 en `reels/`.

```bash
cd reels
npm ci
npm run dev
```

Consultar `reels/README.md` para estructura, reutilización y comandos.

## Primera prueba de edición

El MP4 completo sin subtítulos está en
[`output/reel-v1-sin-subtitulos.mp4`](output/reel-v1-sin-subtitulos.mp4).
En GitHub, abrir el archivo y usar **Download raw file** para descargarlo.

Formato: 1080×1920, 30 fps, duración 54,13 segundos.
Incluye recortes conservadores de pausas, zooms suaves y audio original.
La composición `ReelTrialV1` es experimental y no define una plantilla final.
